# Audit notes (November 2026)

Scope of this pass: read-only review of the uploaded snapshot of `YTX-Feature-Lab`, plus one fix.
**Nothing here was compiled or run.** The review environment had no Gradle, Android SDK or network,
and the snapshot has no git history, so it could not be diffed against upstream
(`Koustubh12345/YTXTube`). Device-tested: no.

## Fixed in this pass

**Look profiles could write wrong-typed settings (startup crash risk).**
`Profiles.apply` wrote whatever JSON type it found. A float such as `ambient_intensity = 1.0` is
serialised as `1` by `org.json`, comes back as an Int, and was stored with `putInt` over a float
key; `AmbientSettings.init` then calls `getFloat` on it, which throws `ClassCastException` on every
launch. The same applied to any hand-edited or pasted profile with a wrong type, and to unknown keys.

Now `ProfileRules` (Profiles.kt) holds a registry of the keys a profile may set and their stored
types (tweak keys come from `Tweaks.keyTypes`). Values are converted to that type, and unknown keys
or unconvertible values are skipped. Unit tests: `ProfileRulesTest`. Preference keys are unchanged.
